# Memoria Descritiva

O projeto consiste no desenvolvimento de um instrumento musical virtual, inspirado na ocarina tradicional, utilizando a biblioteca p5.js. O input principal é o teclado do computador, através do qual o utilizador pode controlar os diferentes orifícios do instrumento. Cada tecla corresponde a um orifício, permitindo criar diferentes combinações através da interação simultânea com várias teclas.

A expressão resulta da conversão dessas combinações numa sequência binária, em que cada posição representa o estado de um orifício: aberto ou tapado. Através de um sistema de mapeamento (fingering), cada combinação é associada a uma frequência específica e à respetiva nota musical. O output consiste na produção de som em tempo real, através de um oscilador da biblioteca p5.sound, acompanhada por uma representação visual dos orifícios tapados e da nota musical reproduzida.

No início, é declarada a variável array holes, responsável por armazenar a informação de cada orifício da ocarina. Cada objeto contém diferentes propriedades, como o identificador (id), a tecla correspondente (key), as coordenadas de posição (x e y), o raio (r), o estado do orifício (covered) e a sua visibilidade (visible). Desta forma, é possível controlar individualmente cada orifício através de um único array, facilitando a sua manipulação ao longo do código.

De seguida, são declaradas as variáveis relacionadas com o som. A variável oscillator é utilizada para armazenar o oscilador, um componente que gera um sinal periódico que, dependendo da sua frequência, pode produzir um som mais grave ou agudo. Este elemento permite simular as diferentes notas musicais da ocarina. A variável audioStarted funciona como um indicador para verificar se o sistema de áudio já foi iniciado, enquanto currentNote armazena o nome da nota que está a ser reproduzida, permitindo apresentá-la visualmente no ecrã.

É também declarada a variável fingering, que funciona como um dicionário responsável por armazenar as frequências, os nomes das notas e as respetivas combinações de orifícios através de código binário. Cada combinação é representada por uma sequência de doze valores, sendo 1 correspondente a um orifício tapado e 0 a um orifício aberto. Desta forma, o programa consegue identificar a posição dos orifícios e associá-la à respetiva nota musical.

A seguir, é declarada a função setup(), responsável pela configuração inicial do programa. Nesta função é criado o canvas através de createCanvas(800, 650), definindo as suas dimensões. O canvas é associado a um elemento HTML através de cnv.parent("instrument-stage"), permitindo organizar a sua posição na página. Através de cnv.style() são definidas as propriedades visuais do canvas, utilizando uma imagem SVG da ocarina como fundo. Ainda dentro de setup(), é inicializado o oscilador através de new p5.Oscillator("sine"), utilizando uma onda sinusoidal para produzir o som. Com oscillator.amp(0), a amplitude é inicialmente definida como zero, mantendo o instrumento em silêncio até existir uma interação do utilizador. Por fim, é utilizado window.addEventListener("blur", releaseAllKeys) para evitar possíveis erros quando o utilizador mantém uma tecla pressionada e troca de janela. Desta forma, todos os orifícios são automaticamente libertados quando a página é trocada.

Na função draw() Inicialmente, utiliza-se clear() para limpar o conteúdo anterior do canvas. De seguida, é chamada a função drawHoles(), responsável por representar graficamente os diferentes orifícios da ocarina. Logo são definidas as propriedades visuais do texto que apresenta a nota musical atual. Com text(currentNote, 400, 475), é apresentada a nota correspondente à combinação de orifícios utilizada. A função drawHoles() é responsável por desenhar individualmente cada orifício. Para isso, utiliza-se um ciclo for...of, que percorre todos os objetos armazenados no array holes, permitindo aceder às propriedades de cada um através da variável h.

Posteriormente, são desenhados os orifícios através da função ellipse(), utilizando as coordenadas e o raio armazenados em cada objeto. Primeiro é criada uma pequena sombra com transparência, seguindo-se o círculo principal com uma tonalidade azul escura. Através de uma segunda condição if (h.covered), é verificado se o orifício está tapado. Caso seja verdadeiro, a sua aparência é alterada através de uma nova cor, um contorno e um pequeno reflexo, criando uma distinção visual entre os orifícios abertos e tapados. Por fim, é apresentada a tecla correspondente a cada orifício através de text(h.key.toUpperCase(), h.x, h.y)`, convertendo as letras para maiúsculas e posicionando-as no centro dos respetivos círculos.

A função startOcarina() é responsável por iniciar o sistema de áudio quando o utilizador começa a interagir com o instrumento. É declarada como uma função assíncrona através de async, permitindo utilizar await para aguardar pela inicialização do áudio. Através de uma condição if (!audioStarted), é verificado se o sistema já foi iniciado. Caso ainda não tenha sido, utiliza-se userStartAudio() para permitir a reprodução de som após uma interação do utilizador com a página. A função updateOcarinaSound() é responsável por transformar as combinações dos orifícios nas respetivas notas musicais. Inicialmente, é verificado se o sistema de áudio já foi iniciado através de uma condição if (!audioStarted), evitando executar operações sonoras antes da sua inicialização. De seguida, é declarada a variável combination, inicialmente vazia, que irá armazenar a sequência binária correspondente ao estado dos orifícios.

Através de outro ciclo for...of, são percorridos todos os elementos do array holes. Dentro deste ciclo é utilizado o operador ternário ? :, que permite verificar se cada orifício está tapado ou aberto. Caso h.covered seja verdadeiro, é acrescentado o valor "1" à variável combination; caso contrário, é acrescentado o valor "0". Depois de construída a sequência, é utilizada a variável result para procurar a combinação correspondente dentro do dicionário fingering. Através de fingering[combination], o programa procura a frequência e o nome da nota associados à sequência binária. Uma condição if (result === undefined) permite verificar se a combinação existe no array fingering. Caso não exista, a nota apresentada é substituída por um traço e a amplitude do oscilador é reduzida a zero.

Quando a combinação é válida, a variável currentNote recebe o nome da respetiva nota musical através de result.note. De seguida, oscillator.freq(result.frequency, 0.08) altera a frequência do oscilador de acordo com a combinação identificada, enquanto oscillator.amp(0.18, 0.08) controla a amplitude do som, permitindo uma transição gradual entre diferentes notas.

Para permitir a interação com o teclado, são utilizadas as funções keyPressed() e keyReleased(), que detetam, respetivamente, quando uma tecla é pressionada e quando é libertada. Na função keyPressed(event), é inicialmente chamada startOcarina() para garantir que o sistema de áudio está ativo. A propriedade event.key permite identificar a tecla pressionada, sendo utilizada a função toLowerCase() para converter o seu valor em minúsculas e facilitar a comparação com as teclas armazenadas no array holes.

É também utilizada a condição if (event.repeat) para impedir que o programa processe repetidamente a mesma tecla enquanto esta permanece pressionada. De seguida, um ciclo for...of percorre os diferentes orifícios, comparando a tecla pressionada com a propriedade key de cada objeto. Quando é encontrada uma correspondência, a propriedade covered passa a ser verdadeira, indicando que o orifício está tapado. Nesse momento, é chamada updateOcarinaSound() para atualizar a combinação binária e reproduzir a nota correspondente. O comando break interrompe o ciclo assim que o orifício é identificado, evitando verificações desnecessárias.

A função keyReleased(event) segue uma lógica semelhante, mas é executada quando o utilizador deixa de pressionar uma tecla. Através de event.key.toLowerCase(), é identificada a tecla libertada e, utilizando novamente um ciclo for...of e uma condição if, é procurado o orifício correspondente. Quando é encontrada uma correspondência, a propriedade covered passa a ser falsa, indicando que o orifício voltou a estar aberto. De seguida, é chamada novamente updateOcarinaSound() para recalcular a combinação binária e atualizar a nota musical de acordo com o novo estado do instrumento.

Por último, a função releaseAllKeys() permite libertar todos os orifícios simultaneamente. Para isso, utiliza um ciclo for...of que percorre o array holes e altera a propriedade covered de todos os objetos para falsa. No final, é chamada updateOcarinaSound() para atualizar o estado sonoro do instrumento. Esta função está associada ao evento blur anteriormente definido em setup(), funcionando como uma medida de segurança para evitar que os orifícios permaneçam tapados quando o utilizador abandona a janela do navegador.

Desta forma, o projeto combina a deteção de inputs através do teclado, o processamento de combinações binárias e a síntese sonora, criando um instrumento musical virtual que permite ao utilizador explorar diferentes notas através de uma interação inspirada no funcionamento de uma ocarina tradicional.
